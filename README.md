# Goon Squad

Goon Squad (named for its original meaning, the slang association developed later) is a multiplayer first-person shooter featuring various characters. These characters distinguish themselves through their unique playstyles, designs and personalities. The game is developed in Unreal Engine and without the use of generative AI. Except for sound files, almost all assets have been created by me.

If you want to play the game, message me and I will send you codes for the playtest via Steam which allows you to play one versus one matches online with one player hosting.
